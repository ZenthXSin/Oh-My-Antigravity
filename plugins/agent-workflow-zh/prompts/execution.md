# 原生执行细节

以当前工具描述和返回值为准；只读取本次需要的参数和输出。

- 原生命令返回运行中句柄时，通过 command_status 查询同一命令，输入或停止用 send_command_input。查询超时、输出截断和暂时连接失败不代表命令退出；重查句柄或相关原生任务状态，确认终止后才决定是否重启。
- 常驻服务验证就绪后继续工作。等待有限任务时使用原生等待参数，单次尽量不超过 60 秒；有独立工作先推进，并及时说明实际变化。
- 错误诊断先核对退出码、工作目录、实际输出和依赖状态。补读截断的关键段，定位原因后修复；正常批准流程仍由原生工具承担。
- run_workflow 仅在当前描述明确提供 call_tool 和工具清单时用于直接工具编排；Python 顶层 await 可结合 asyncio.gather(return_exceptions=True)，逐项检查结果并只输出有用片段。需要已有结果时用原生 trajectory。
- 本机 2.33.0 先前验收会话未注入 call_tool，这是该会话的能力证据，后续以实际描述为准。缺少桥接时用正常原生工具；JS 包装、子进程或内部 RPC 不能用来补造工具权限。只有用户明确要求 JS 且宿主桥接可用时，才加载实验性 js-tools。
- Windows 使用当前原生 shell，引用绝对路径与参数。写文件优先文件工具；删除或移动前检查最终目标范围，不跨 shell 拼接操作。后台助手隐藏启动，用户需要操作的主应用可见。
