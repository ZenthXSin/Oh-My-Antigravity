安装内容：中文／英文界面切换、Agent 工作原则、持久 Goal 与有限续跑、Antigrative Dashboard、桌面主 Agent 多渠道聚合与思考强度滑条。

要求：Windows x64。已有 Antigravity 2.33.0 时请完全退出。
尚未安装时，使用包内官方 2.33.0 安装程序离线安装。
官方安装程序保持原样，使用 SHA256 与 Google 数字签名验证。
Node.js 和 Python 运行时随包提供，无需另装开发工具。

语言入口：设置 → 通用 → 语言。切换语言会刷新界面，请先发送或保存草稿。
首次安装默认进入本地工作区，无需登录或配置提供商。使用 Agent 时在设置 → 通用 → 模型接入选择 API 聚合，填写渠道后保存并启用，也可主动选择官方服务登录。已有接入和会话配置保留。
每模型最大输入 Token 默认 275000、最大输出 Token 默认 125000，均可修改。
渠道与模型变更后须完全退出再启动；档位名称保留英文，Ultra 粒子动画由闪电按钮开关。
四种接口协议已验证本机工具流程；真实付费渠道需用自己的密钥确认兼容性。
快捷入口保留 --disable-gpu，并启用仪表盘所需的本机调试地址。修复 Windows EXDEV 配置写入导致的启动黑屏。
如临时目录报错 5，将安装包与 launch-setup.ps1、Install-OhMyAntigravity.cmd 放在一起，双击 CMD；它会选用当前用户可写的临时目录。

原厂应用与已有插件备份保存在安装目录 backups。卸载恢复本增强包管理的文件和设置，官方 Antigravity、Goal 与会话数据保留；升级后不覆盖未知应用归档。
此包目前只适配已审核的 2.33.0 前端；少数扩展或服务端动态文案仍可能保留英文。
