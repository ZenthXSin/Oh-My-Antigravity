# Oh My Antigravity

Antigravity 的 Windows 社区增强包：中文／英文界面切换、桌面主 Agent 多渠道聚合、原生工作流优化，以及内置 Antigrative Dashboard。

**增强包 1.4.5** 适配 **Windows x64、Antigravity 2.33.0**。首次安装默认进入本地工作区，无需登录或配置提供商；使用 Agent 时再添加 API 渠道，也可主动选择官方服务登录。已有接入设置保留，工具调用继续走原生审批。

- **语言设置**：在「设置 → 通用 → 语言」选择简体中文或 English。覆盖项目菜单、权限、设置、任务及常用界面；少数第三方扩展和服务端动态文案可能仍为英文。
- **桌面主 Agent 多渠道聚合**：支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Gemini 四种协议，参考 CC Switch 的渠道管理与协议适配架构。切换模式或模型后须完全退出并重新启动 Antigravity。
- **推理强度滑条**：展示当前模型实际配置的全部档位，标签保持英文。Ultra 档位向右发射粒子；默认遵循系统的减少动画偏好，用户可主动点击闪电开关覆盖并启用动画。
- **每模型用量上限**：最大输入默认 275,000 tokens、最大输出默认 125,000 tokens，可分别修改。输入上限通过原生上下文控制生效，输出上限写入各协议的实际字段；实际可用上限仍由模型和服务端决定。
- **Agent 工作原则**：先理解用户的动机、期望成果和推进方式，持续完成已授权任务。减少例行播报、重复规则与无关检查；遇到问题及时说明。编码强调清晰职责、低耦合与模块化，验收优先操作真实产品。
- **Goal**：按会话保存目标、验收条件和检查点；用户明确开启后可有限续跑，支持查询、暂停、恢复与取消。
- **Dashboard**：内置 [Antigrative Dashboard](https://github.com/ATtacK030130/antigrative-dashboard)，展示原生用量、速度、缓存及上下文统计。
- **启动兼容**：保留 `--disable-gpu`，修复 Windows `EXDEV` 配置写入导致的黑屏，并为仪表盘启用仅监听本机的调试地址。

使用安装包时，已安装 2.33.0 的用户先完全退出 Antigravity；尚未安装的用户由包内未经修改的官方 2.33.0 安装程序完成离线首次安装，然后安装增强内容。包内提供所需 Node.js 与 Python 运行时，无需另装开发工具。本地工作区无需登录。官方服务保留真实登录流程。

若安装时出现临时目录错误 5，把随附的 `Install-OhMyAntigravity.cmd` 和 `launch-setup.ps1` 与安装包放在同一目录，双击 CMD 启动；它会检查当前用户可写的临时目录，并隔离 Windows PowerShell 模块路径。

安装前核对安装包随附的 SHA256。官方安装器在构建与首次安装时核对固定 SHA256 和 Google 数字签名；社区增强安装包自身目前未签名。

语言切换会刷新界面，请先发送或保存草稿。仪表盘入口为「⋮ → 扩展 → Antigrative Dashboard」，输入框底部的统计图标也可查看详情。

四协议已在原生 Antigravity 会话中完成本机服务替身的工具审批与结果闭环。后续真实 OpenAI Responses 渠道在修正工具 schema 后，用户已确认桌面 Agent 连接正常；其余真实渠道和模型尚未逐一验证。语言切换、渠道管理、强度滑条和模式重启也已实际操作。范围与协议字段说明见 [多渠道与模型设置](docs/channel-routing.md)。

卸载增强包会恢复其管理的应用文件和配置，保留官方 Antigravity、会话及 Goal 数据。应用升级后不会覆盖未知归档；新版本需要重新适配。

源码构建、仓库收录范围及依赖说明见 [仓库说明](docs/repository.md)。官方安装器、原版前端、构建产物、个人配置和运行数据均不进入此源码仓库。
